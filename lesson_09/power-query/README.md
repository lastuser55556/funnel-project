# Практика ОП.03 · Power Query: объединение источников

[Исходное задание Макарова](https://algorthimization-course-vvodnoe.vercel.app/op03-informacionnye-tehnologii/lessons/09-power-query-combine-merge/materials.html). Папки incoming, lookup, later и backup взяты из архива преподавателя. В исходном incoming три CSV за 23–25 сентября.

## Запросы

1. В Power Query создайте текстовый запрос `lab_root` c абсолютным путём к распакованной папке. Шаблон находится в `queries`. Имя файла без расширения соответствует имени запроса.
2. Добавьте пустые запросы в порядке: `leads_raw`, `sources_lookup`, `statuses_lookup`, `leads_with_sources`, `leads_combined`, `unmatched_sources`. Вставьте M из одноимённых файлов через расширенный редактор.
3. Загрузите `leads_combined` и `unmatched_sources` отдельными таблицами на одноимённые листы. Для промежуточных запросов выберите «Только создать подключение».
4. Повторите контрольные обновления по условию. После добавления файла за 26 сентября проверьте REQ-108, затем добавьте одну строку `tiktok,TikTok,social` в справочник. После обновлений с файлами за 27 и 28 сентября в итоговом отчёте должна остаться только REQ-121.
5. Сохраните книгу `result/power_query_combined.xlsx` и сделайте контрольные скриншоты в Excel.
